# SkillSwap - Grupp 14

Detta repository innehåller koden för vårt grupparbete i kursen Digital Design (WD205I) på Högskolan Kristianstad.

## Om projektet
SkillSwap är en webbplattform som vi bygger för att studenter ska kunna dela med sig av sina kunskaper och ställa frågor till varandra. Tanken är att skapa ett enkelt och användarvänligt flöde för kunskapsutbyte.

## Tekniker vi använder
- Frontend: HTML, CSS och Bootstrap 5 för gränssnitt och UI/UX.
- Backend: PHP.
- Databas: MySQL.
