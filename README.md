# SkillSwap - Grupp 14

Detta repository innehåller koden för vårt designprojekt i kursen Webbdesign för social interaktion på Högskolan Kristianstad.

## Om projektet
SkillSwap är en webbplattform skapad för att studenter ska kunna dela med sig av sina kunskaper och ställa frågor till varandra. Systemet tillåter användare att skapa konton, publicera inlägg, samt hantera sin information (CRUD).

## Tekniker vi använder
- **Frontend:** HTML, CSS och Bootstrap 5 för ett responsivt gränssnitt.
- **Backend:** PHP för serverlogik.
- **Databas:** MySQL för lagring av data.

## Installation
1. Importera den medföljande SQL-filen i phpMyAdmin.
2. Konfigurera databasanslutningen i `assets/config/db.php`.
3. Kör projektet via en lokal server eller GitHub Codespaces.
